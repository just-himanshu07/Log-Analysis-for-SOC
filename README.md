# 🔐 Log Analysis — SOC Hands-on Labs

A collection of hands-on SOC labs covering Windows and Linux log analysis, PowerShell event monitoring, and security event investigation.

## 🎯 Objectives

- Understand Windows and Linux log sources.
- Analyze authentication and system events.
- Investigate PowerShell activity using Windows Event Viewer.
- Identify suspicious behavior through log analysis.
- Develop practical SOC Analyst investigation skills.

## 🧪 Day 01 — Introduction to Log Analysis

**Objective:** Understand basic log analysis and investigate PowerShell activity on Windows.

**Topics Covered:**
- Fundamentals of log analysis
- Windows and Linux log sources
- Linux authentication logs
- PowerShell Script Block Logging
- Windows Event ID 4104

**Practical Task:**
Execute a PowerShell command, locate the corresponding event in Windows Event Viewer, and document the findings.

**Evidence:** Screenshots of relevant Windows PowerShell events.
